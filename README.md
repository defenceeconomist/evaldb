# Defence Evaluation Database

A static library of 28 screened defence evaluation and audit records for MOD business cases. The first page shows a searchable table with left-side filters; report titles open detailed summaries, evidence limits and original sources. There is no shortlist functionality.

## Run locally

```sh
python3 -m http.server 8000 --directory ui/dist
```

Open http://localhost:8000/. The existing Mac mini portal serves the same files at http://luke-mac-mini.local/evaluation-database/.

## Edit and build

The editable catalogue and screening decisions are in `ui/content/`. These retain the full editorial history of 47 records. The builder publishes only the 28 records marked `Include`; the 19 conditional records are omitted from the public data, downloads, review table and detail pages.

```sh
python3 ui/scripts/build_site.py
python3 ui/scripts/validate_content.py
node --check ui/dist/app.js
```

Interface source files are `ui/dist/index.html`, `evaluation.html`, `app.js` and `styles.css`. Data, CSVs and documentation in `ui/dist/` are regenerated by the builder. Serve only `ui/dist/` as the public site. The matching CSV files in `outputs/` are also regenerated.

## Power BI

Import `outputs/evaluation_summaries.csv` with `evaluation_id` as the stable key. Use a Table visual, dropdown slicers for the sidebar filters, and a detail page with drill-through on the record ID. Multi-value fields use semicolon separators. Keep date precision as supplied. Layout and import guidance are in `ui/docs/design-decisions.html`.

See [the UI maintenance guide](ui/README.md) for further details. Browser integration checks are in `ui/scripts/validate_browser.mjs`; set `PLAYWRIGHT_MODULE` and optionally `LIBRARY_BASE_URL` for your environment.
