# Defence Evaluation Library

Public site: http://luke-mac-mini.local/evaluation-database/

The public library contains only the 28 records marked `Include`. The full 47-record catalogue and review remain in `content/` as editorial sources. The builder filters public data, CSV downloads, review documentation and related-record links to the published set.

The first page is a searchable table with left-side dropdown filters; report titles open a separate detail page. There are no shortlists or browser-saved state. The existing Mac mini portal serves `dist/` directly.

Run `python3 scripts/build_site.py`, `python3 scripts/validate_content.py` and `node --check dist/app.js` from this directory. Authored interface files are in `dist/`; data, CSVs and documentation are generated by the builder. Parent `outputs/` CSVs are refreshed as well.

For Power BI, import `dist/evaluation_summaries.csv`, with one row per evaluation and `evaluation_id` as the stable key. Use a Table visual and an evaluation_id drill-through page. See `docs/design-decisions.html` for field, layout and import guidance. This is a static website prepared for a future Power BI rebuild.
